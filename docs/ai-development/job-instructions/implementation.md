# Implementation Job Instructions

## 対象ジョブ

- 実装

## 着手条件

実装ジョブは次をすべて満たす Issue だけを対象にします。

- 設計確定済み。
- 未確定事項なし。
- Open ブロッカーなし。
- 小さく分解済み。
- 検証方法が明確。
- セキュリティ、権限、個人情報、入力検証に関わる判断が未確定ではない。
- レビュー指摘が triage 済み。
- `ready-for-implementation` 相当の状態である。

## 実装範囲

- `docs/requirements.md` と関連設計に沿う。
- 初期版の対象外である認証、外部 API、サーバー保存、複数ユーザー同時編集へ勝手に拡張しない。
- 変更は小さく、レビューしやすい単位にする。
- 既存文書の大量移動・削除は行わない。

## 停止条件

次のいずれかに該当する場合は実装せず、`docs/ai-development/work-log.md` に停止理由と次アクションを記録します。

- Open ブロッカーがある。
- Issue が大きすぎる。
- 設計が未確定。
- Slack 回答待ちが残っている。
- 検証方法が明確でない。
- セキュリティ、権限、個人情報、入力検証の判断が未確定。
- レビュー指摘が triage されていない。

## 検証

原則として次を実行します。

```bash
npm run typecheck
npm test
npm run build
```

モバイル UI を変更した場合は README の Mobile verification 観点も確認します。

## 出力

- 対象 Issue
- 作成 PR
- 変更サマリ
- 実行した検証と結果
- 未確認事項
- 変更したラベル
- 次アクション
