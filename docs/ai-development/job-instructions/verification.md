# Verification Job Instructions

## 対象ジョブ

- テスト観点レビュー
- 検証

## 目的

要件、実装タスク、直近変更、Issue / PR の状態に基づき、必要な検証観点と実行結果を整理します。

## 基本検証コマンド

```bash
npm run typecheck
npm test
npm run build
```

実行できない場合は理由と代替確認方法を記録します。

## 観点

- 候補追加、編集、削除。
- 候補不足時の抽選停止。
- 抽選結果が抽選対象候補から選ばれること。
- 抽選済み除外設定の ON / OFF。
- 全候補抽選済み時に自動リセットしないこと。
- `localStorage` 復元、不正データ、保存失敗。
- 空文字、空白のみ、120文字超の入力拒否。
- 同名候補の内部 ID 区別と表示上の識別。
- 候補名の XSS 安全表示。
- 長い候補名とスマートフォン幅の表示崩れ。

## Mobile verification

モバイル UI 変更時は README の `Mobile verification` に従い、390px 前後で次を確認します。

- 候補追加フォーム、候補一覧、抽選パネルが横スクロールなしで表示される。
- 長い候補名が折り返され、編集・削除ボタンが操作できる。
- 抽選開始、抽選済み状態リセット、候補全削除ボタンが画面幅内に収まる。
- 抽選結果の長い候補名が表示領域からはみ出さない。

## 停止条件

- 検証対象の要件または受入条件が不明。
- 実行すべき検証コマンドが不明。
- テスト失敗の原因が仕様未確定事項に依存する。
- 高リスク変更の人間承認が未完了。

## 出力

- 対象 Issue / PR
- 実行コマンドと結果
- 未実行理由
- 失敗内容
- 残リスク
- handover 候補
- 次アクション
