## 追加で仕様化したい事項

### 同名候補識別仕様

- 同名候補が複数ある場合、各候補には画面上で識別できる補助情報を表示する
- 初期版では登録順番号を表示対象とする
- 編集・削除操作にも同じ識別子を付与する

### 候補名制約

- 候補名は trim 後に 1 文字以上であること
- 候補名の最大文字数は 120 文字とする
- 制約超過時は画面上で明示的にエラー表示する
